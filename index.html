Data and method

Four grains: one row per match (127 columns), one per player per match counted here (53), one per player per match as published (58), one per player per season (51). Every column of every file has a dictionary entry; the export refuses to build if one does not.

Counted
Recounted here from the raw event stream. Measured, and checkable against the supplier — 0 mismatches in 760 player-matches.
Published
The supplier's own tally, copied. Includes every match rating on this page. Checking it against the supplier proves nothing.
Vendor model
79 of the 127 team columns are vendor output whose models are not published — xG, xT, field tilt. Fine for United against United; not a measured quantity.
Derived
Computed here from two columns on the same row. The formula is stated wherever the number is shown.
Rules this page obeys
1
No per-90 rates below 450 minutes. Nobody in 26/27 is close, so GW1 is shown in raw counts only.
2
NaN stays NaN. Seven documented absences across the 38×127 master render as an em dash, never as zero.
3
